============================================================
COMMUNITY SPORTS FACILITIES BOOKING SYSTEM
ORACLE DATABASE SETUP GUIDE
============================================================

PROJECT DATABASE:
Oracle Database 21c Express Edition (XE)

TOOLS:
- Oracle Database 21c XE
- Oracle SQL Developer
- Oracle SQL Developer Data Modeler

============================================================
1. INSTALL ORACLE AND SQL DEVELOPER
============================================================

On a new computer, install:

1. Oracle Database 21c Express Edition (XE)
2. Oracle SQL Developer

Oracle XE normally provides the XEPDB1 pluggable database.

Make sure the Oracle database services are running before
continuing.

============================================================
2. CREATE THE PROJECT DATABASE USER
============================================================

IMPORTANT:
Every computer has its own Oracle Database.

The SPORTS_BOOKING user from the original computer does NOT
automatically exist on another computer.

Create the project user locally.

Open Command Prompt and run:

sqlplus / as sysdba

Then run these commands IN THIS EXACT ORDER:

ALTER SESSION SET CONTAINER = XEPDB1;

CREATE USER SPORTS_BOOKING IDENTIFIED BY SportsBooking123;

GRANT CONNECT, RESOURCE TO SPORTS_BOOKING;

The first command automatically switches the session to
XEPDB1.

You do NOT need to manually select XEPDB1.

The SPORTS_BOOKING user is therefore created inside XEPDB1.

============================================================
5. DATABASE MODEL
============================================================

The database design was created using Oracle SQL Developer
Data Modeler.

Model file:

Sports_Booking_System.dmd

Relational model:

Sports_Booking_Relational_Model

The model contains 7 tables:

1. SPORT
2. FACILITY
3. MEMBER
4. MEMBER_SPORT
5. BOOKING
6. REVIEW
7. INQUIRY

The model contains the primary keys and foreign-key
relationships between these tables.

============================================================
6. SQL SCRIPT GENERATED FROM THE MODEL
============================================================

The SQL script generated from the relational model is:

Sports_Booking_Database.sql

This script contains the SQL required to create the actual
Oracle database tables and constraints.

The .dmd file = database design/model

The .sql file = SQL used to create the database structure

KEEP BOTH FILES WITH THE PROJECT.

============================================================
7. CREATE THE TABLES
============================================================

After creating the SPORTS_BOOKING connection:

1. Open Oracle SQL Developer.
2. Connect to the SPORTS_BOOKING connection.
3. Open:

   Sports_Booking_Database.sql

4. Make sure the SQL worksheet is connected to:

   SPORTS_BOOKING

5. Press:

   F5

F5 = Run Script

The SQL script will create the project tables and their
constraints.

============================================================
8. CHECK THE TABLES
============================================================

After the SQL script finishes:

1. Expand the SPORTS_BOOKING connection.
2. Find the "Tables" section.
3. Right-click "Tables".
4. Select "Refresh".

The following tables should appear:

BOOKING
FACILITY
INQUIRY
MEMBER
MEMBER_SPORT
REVIEW
SPORT

============================================================
9. OPEN THE DATA MODEL
============================================================

To open the database model:

1. Open Oracle SQL Developer.
2. Open the Data Modeler.
3. Open:

   Sports_Booking_System.dmd

The relational model should show:

SPORT
FACILITY
MEMBER
MEMBER_SPORT
BOOKING
REVIEW
INQUIRY

along with their relationships.

============================================================
